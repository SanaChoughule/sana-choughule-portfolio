# Sana Choughule — Product & Technology Portfolio

A responsive React + Vite portfolio website.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## Deploy

This project can be pushed to a separate GitHub repository and imported into Vercel.
Use the default Vite settings:
- Build command: `npm run build`
- Output directory: `dist`

## Portfolio content

The portfolio includes the selected resume and portrait, product concepts and AI experiments, plus a separately labelled Hatchable website build created for a family member. Keep project status labels accurate and do not present independent concepts as employer- or platform-endorsed products.

## Before publishing

1. Review every project description and confirm status labels.
2. Add the News AI Agent demo URL if you want it linked.
3. Add the final Stay Context public-facing URL if it changes.
4. Confirm the resume is suitable for public download.
5. Check all links, mobile layout and accessibility.
6. Keep API keys and private credentials out of the repository.

The Stay Context concept is independent and is not built, endorsed or production-integrated by Airbnb. Prototype route data should be described as illustrative unless live routing is connected.
